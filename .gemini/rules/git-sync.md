# Git Sync Workflow

- Siempre que el usuario diga "Listo, ponla en el repositorio", "Sube los cambios", "Commit and push", o tras completar una tarea/funcionalidad importante:
  1. Ejecutar `git status` para revisar los cambios.
  2. Ejecutar `git add -A`.
  3. Realizar un commit claro y descriptivo en español: `git commit -m "<tipo>: <descripción concisa>"`.
  4. Ejecutar `git push origin main`.
  5. Confirmar al usuario con el hash y mensaje del commit.
